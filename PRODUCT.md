# Financial Work

Рабочее пространство частного инвестора: проверить капитал и результат,
изучить стратегии, инвестировать, пополнить счёт и подать заявку на вывод.
Основные сценарии: вход → обзор → стратегия → операция → история.
Интерфейс на русском, валюта у каждого значения, данные только из действующего API.
Next.js App Router, React, Tailwind CSS, TypeScript, FSD.
Администратор обрабатывает расчёты через защищённые сервером endpoints.
