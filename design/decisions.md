# Решения по миграции

- Визуальная основа — `cu-schedule-ai 2`, выбранная пользователем.
- Повторный запрос Mobbin MCP 2026-11-03 вернул `requires a paid plan`.
- App Router маршрутизирует приложение; слой страниц FSD назван `views`.
- Общие графики — SVG с HTML-подписями и таблицей точных значений.
- Backend остаётся источником данных и проверяет сессию и права.
- Подключён существующий защищённый роут Telegram-привязки.
- Старые Vite-входы удалены, `main.html#…` поддержан переходником.
- Каждый коммит ограничен 150 добавленными и удалёнными строками суммарно,
  включая lock-файлы. Проверка размеров выполняется перед push.
